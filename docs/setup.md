# Setup notes

Follow the root README. If the Language Lab cannot reach FastAPI, confirm it runs on port 8000. On a phone, use the same-origin HTTPS proxy described in `frontend/README.md`; `127.0.0.1` on the phone refers to the phone. Microphone capture requires HTTPS or localhost. If a model is absent, prepare it while connected and verify transcription offline on the target device. Use a supported browser and allow enough storage for model artifacts.
