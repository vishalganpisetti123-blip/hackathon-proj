# AI/ML demo runbook

1. Open `/transcribe/`. No login is required. Select **Auto** spoken language and show English as the default presentation.
2. Record a short mixed-language phrase or upload a consented test clip. The browser downloads the selected local model if it is not prepared. Show the machine original, editable transcript and word/sentence views.
3. Check a spelling suggestion against the recording. Switch the presentation to Original and then to another language. Show that the original is preserved.
4. Save the session and export the text. Prepare the website and speech model, then repeat with connectivity disabled on the target device.
5. Open `/demo/` for the Language Lab. Select a code-switching example and show token labels, boundaries, transliteration, normalized text and JSON. Explain that this is an auditable local rules pipeline, separate from the browser speech model.

Do not claim measured accuracy from the illustrative website copy. For a judge, use a known recording and compare its transcript with a reference sentence.
