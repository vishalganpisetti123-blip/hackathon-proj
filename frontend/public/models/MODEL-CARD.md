# FieldProof local language assets

The website provides ten spoken-language choices: Hindi, Bengali, Marathi, Telugu, Tamil, English, Mandarin, Spanish, Arabic and French, plus Auto. The choice is passed to a multilingual Whisper ASR model as a language hint. Choosing a language does not imply that the generic model was retrained or verified for that language. Hindi, Bengali, Marathi, Telugu and Tamil can use separate locally hosted specialists. Auto and the multilingual model remain available for mixed speech.

`word-language.json` is a local character n-gram classifier trained on English, romanized Hindi and romanized Telugu word lists. It is **not** an ASR model. On a 3,000-word held-out sample it scored 80.0% top-choice accuracy; with abstention, 86.8% on the 79.3% it labeled. These isolated-word scores do not measure spontaneous speech or code switching. New languages do not receive invented classifier labels; script tags and uncertainty are shown instead.

`telugu-romanized-lexicon.json` contains 48,905 unambiguous romanized/native Telugu pairs derived from the manually collected portion of AI4Bharat Aksharantar. It supports reviewable suggestions such as `was tundi → vastundi (వస్తుంది)` while preserving the raw machine transcript and recording. It is not an automatic correction model. Source and license: [Aksharantar](https://huggingface.co/datasets/ai4bharat/Aksharantar), CC BY 4.0 for manually collected pairs.

`fieldproof/whisper-telugu-small/` contains the config/tokenizer and locally exported 8-bit ONNX weights from [vasista22/whisper-telugu-small](https://huggingface.co/vasista22/whisper-telugu-small), Apache 2.0. We added multilingual generation metadata from the base Whisper small configuration so Transformers.js can set Telugu decoding. The two ONNX weights total approximately 414 MB and are git-ignored. SHA-256: encoder `cc19fc5d5f4441ab0671ea8a1135a626b7c50f540334f271062ffb491fa00303`; merged decoder `7702452e2d6d775f9a541d153d86355db7feb27593926bac6bf2789cd745f1eb`.

In six clean Telugu FLEURS read-speech clips, the quantized Transformers.js CPU runtime measured 9.9% word error versus 165.4% for the generic Python Whisper small baseline. These six clips are a diagnostic only; the specialist's own model card reports FLEURS evaluation, so this is not an independent release test. Noisy field speech, spontaneous code switching, romanized output and physical-phone performance are unmeasured. Android uses a separate GGML conversion described below.

`fieldproof/whisper-hindi-small/` is a locally exported 8-bit ONNX pack from [vasista22/whisper-hindi-small](https://huggingface.co/vasista22/whisper-hindi-small), Apache 2.0. Its two weight files total approximately 414 MB and are git-ignored. SHA-256: encoder `92a6be683f698627b1209dbe4dded058fd0c6ce3a690a15ed1b77e135fce06bc`; merged decoder `09787fe72d80503157054567f4e0931d1a2e2b70876bfb3348b77773b3cb0111`. On six clean Hindi FLEURS read-speech clips, its quantized Transformers.js CPU runtime measured 12.1% word error versus 56.4% for generic Python Whisper small. This is a small benchmark-family check, not a field accuracy result.

The website packages are loaded only after a person selects the specialist; the large weights are excluded from service-worker precache and must be prepared on each device before offline use. These checks use just six clean FLEURS clips per language. Bengali's source model includes FLEURS in its own development, and Marathi's remaining error rate is high. No field-ready claim follows from these numbers.

The Android app also offers a separate optional Telugu GGML pack from [bhaskaro/ainotes-whisper-telugu-q5_1](https://huggingface.co/bhaskaro/ainotes-whisper-telugu-q5_1), Apache 2.0. It measured 18.5% word error versus 153.1% for the generic phone model in the same whisper.cpp CPU test on six clips, with timestamp tokens disabled. The APK and specialist have not been tested together on a physical phone.

Android also offers optional SHA-256-verified Hindi and Tamil Q5_1 packs from [ukta-app/indic-whisper-ggml](https://huggingface.co/ukta-app/indic-whisper-ggml), Apache 2.0; a Bengali Q5_1 pack from [bhaskaro/ainotes-whisper-bengali-q5_1](https://huggingface.co/bhaskaro/ainotes-whisper-bengali-q5_1), MIT; and a Marathi Q5_1 pack from [bhaskaro/ainotes-whisper-marathi-q5_1](https://huggingface.co/bhaskaro/ainotes-whisper-marathi-q5_1), Apache 2.0. Each is 190,085,487 bytes. The exact hashes and download URLs are in `mobile/src/models.ts`. Same-runtime six-clip WERs were Hindi 10.7%, Tamil 26.6%, Bengali 38.5% and Marathi 58.5%; see `training/RESULTS.md` for generic comparisons and limitations.

See `training/README.md` and `training/RESULTS.md` in the source workspace for reproducibility, ten-language diagnostics, input hashes and limitations.
